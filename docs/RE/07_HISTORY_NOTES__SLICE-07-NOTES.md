# HOTLINE ABAKAN — VERTICAL SLICE 07

## Что это за проход

Slice 07 продолжает Slice 06 не количеством оружия, а связностью правил комнаты. Цель — чтобы игрок мог решить одну ситуацию несколькими способами и потом увидеть последствия на обратном пути.

## Новый climax: читаемый 2v1

В гостиной теперь два противника:

- **opportunist** конкурирует за единственную трубу;
- **flanker** старается обойти игрока сбоку, пока другой владеет attack-token;
- одновременно атаку начинает только один враг, поэтому 2v1 не превращается в нечитабельный спам;
- увидевший игрока противник поднимает локальную тревогу: напарник идёт к последней известной позиции/источнику шума.

Это первый экзамен на уже изученные правила: обзор, шум, дверь, parry, dodge, knockdown и world-weapon.

## Дверь и бросок теперь связаны

- door bash проверяет сторону створки: сбить можно врага, который реально находится по другую сторону двери;
- брошенная труба сталкивается с закрытой дверью, распахивает её, падает рядом и создаёт сильный шум;
- после этого враги могут пойти на шум — один предмет связывает weapon lifecycle, door system и AI perception.

## Миссия заканчивается возвращением

После кассеты и обоих врагов в гостиной экран результата **не появляется сразу**.

Задача меняется на: **вернуться на лестничную площадку**.

Игрок идёт обратно через уже открытые комнаты. На полу остаются следы предыдущих убийств, а на лестнице включается зелёный extraction-marker. Result/grade появляется только после физического возвращения к точке входа.

## Style feedback

В правом верхнем блоке теперь видны:

- score;
- multiplier;
- словесный темп: `ТИХО / ТЕМП / РАЗНООБРАЗНО / ИМПРОВИЗАЦИЯ / БЕЗ ОСТАНОВКИ`;
- полоска времени до сброса style-chain.

При смерти в финальной комнате оба финальных врага восстанавливаются, а score snapshot откатывается к началу сцены — финал нельзя фармить повторными убийствами через намеренную смерть.

## Управление

- `WASD` — движение
- `J` — быстрый
- `K` — тяжёлый / knockdown
- `L` держать — block
- `L` непосредственно перед контактом — parry
- `SPACE` — короткий dodge
- `F` — context: дверь / добивание / кассета / поднять или положить трубу
- `E` — метнуть трубу
- `R` — restart текущей сцены

## Что проверить руками

1. В финальной гостиной не должны одновременно прилетать две атаки.
2. Второй враг должен пытаться менять угол, а не просто вставать в очередь за первым.
3. Открытие/удар двери должно работать только по противоположной стороне створки.
4. Метни трубу в закрытую дверь — дверь должна открыться, труба остаться world-object, враги должны услышать шум.
5. Убей обоих — result screen ещё не должен появиться.
6. Вернись через квартиру к стартовой лестнице и зайди в зелёный marker — только там появляется grade.
7. На обратном пути должны оставаться следы предыдущих боёв.

## Техническая проверка

Contract suite проверяет:

- 7 enemy instances / 6 combat scenes;
- ровно два finalPair enemy;
- opportunist + flanker;
- attack-token coordination;
- local alert propagation;
- directional door bash;
- pipe → door interaction;
- authored extraction point у входа;
- persistent aftermath;
- style timer UI;
- отсутствие оригинальных Hotline Miami `.exe/.wad/.ogg/.dll` в ZIP.

Route-test отдельно доказывает маршрут с радиусом игрока до гостиной и обратно к лестнице, плюс доступность кассеты, трубы и extraction-marker.

## Ограничение сборки

Three.js / GLTFLoader / OBJLoader всё ещё подключаются через jsDelivr. Сборочная среда не дала скачать vendor-копии локально. Поэтому этот ZIP пока не является полностью offline-build. Gameplay/assets проекта локальные.
